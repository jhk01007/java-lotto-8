# 🎰 로또 발매기

## ✅ 기능 요구사항

### **➡️ 입력**

1. **로또 구입 금액**
    - 1000원 단위로 입력

    ```
    구입금액을 입력해 주세요.
    8000
    ```

2. **중복되지 않는 1~45사이의 당첨 번호 6개**
    - 번호는 쉼표(,)를 기준으로 구분

    ```
    당첨 번호를 입력해 주세요.
    1,2,3,4,5,6
    ```

3. **당첨 번호 6개와 중복되지 않는 보너스 번호 1개**

    ```
    보너스 번호를 입력해 주세요.
    7
    ```


### **🔁 세부 로직**

1. 금액에 맞게 로또 번호를 발행한다.
    - 금액 / 한장당 가격(1000)개의 로또를 발행한다.
    - 로또 번호는 1~45 사이의 중복되지 않는 숫자 6개로 이루어진다.
    - 로또 번호 6개는 오름차순이어야 한다.
2. 구매한 로또 번호와 당첨 번호 및 보너스 번호를 비교하고 관련 통계를 계산한다.
    - 등수별 당첨 갯수를 계산한다.
    - 수익률을 계산한다.

### **⬅️ 출력**

1. **발행한 로또 수량 및 번호**
    - 각 로또는 오름차순으로 출력돼야 한다.

    ```
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43] 
    [3, 5, 11, 16, 32, 38] 
    [7, 11, 16, 35, 36, 44] 
    [1, 8, 11, 31, 41, 42] 
    [13, 14, 16, 38, 42, 45] 
    [7, 11, 30, 40, 42, 43] 
    [2, 13, 22, 32, 38, 45] 
    [1, 3, 5, 14, 22, 45]
    ```

2. **당첨 내역**

   (요구사항에 명시되있진 않지만) 등수가 낮은 순으로 정렬하여 출력돼야 한다.

    ```
    당첨 통계
    ---
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```

   당첨 기준과 금액

    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
3. **수익률**
    - 수익률은 소수점 둘째자리에서 반올림해야 한다.

    ```
    총 수익률은 62.5%입니다.
    ```


### **⚠️ 예외 처리**

**[규칙]**

1. 예외 상황시 에러 문구를 출력해야 한다.
2. 에러 문구는 “[ERROR]”로 시작해야 한다.

    ```
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ```

3. 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고 실패한 요청부터 다시 시작되어야 한다.
4. `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

## 💻 주요 프로그래밍 요구사항

- [x]  인덴트는 2까지만 허용한다.
- [x]  값은 하드 코딩하지 않는다. (private static final 활용)
- [x]  Java Enum을 적용하여 프로그램을 구현한다.
- [x]  클래스는 상수, 멤버 변수, 생성자, 메서드 순으로 작성한다.
- [x]  변수 이름에 자료형을 포함시키지 않는다.
- [x]  3항 연산자를 사용하지 않는다.
- [x]  함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
    - 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- [x]  else / switch case 문 사용 금지
- [x]  구현한 기능에 대한 단위 테스트를 작성한다. 단, UI 로직은 제외한다.
